About

我是刘文豪，上海大学通信与信息工程学院硕士研究生，关注 Agent Engineering，预计 2028 年毕业。

我相信 AGI，也相信好的 Agent 系统应该是可理解、可调试、可靠且低熵的。我正在寻找 Agent 工程方向的实习机会，希望与优秀的团队一起构建优雅、可控而高效的系统。

我尤其关心 Agent 的运行时、记忆机制、工具编排，以及视觉智能体在真实环境中的可靠执行。
