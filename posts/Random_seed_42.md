# 为什么随机种子常用 42？

在深度学习的数据处理和模型训练代码中，经常能看到随机种子被设为 42。这个选择通常被认为是对道格拉斯·亚当斯科幻作品《银河系漫游指南》（*The Hitchhiker's Guide to the Galaxy*）的致意：作品把 42 设定为一个著名的“终极答案”。后来，42 逐渐成为程序员文化中的常见彩蛋。

## 为什么要设置随机种子

随机种子控制伪随机数生成器的初始状态，使同一套代码在条件相同时更容易得到一致结果。42 对随机数生成没有特殊优势；只要取值在所用库允许的范围内，换成其他固定整数同样可以用于复现。

```python
import random

import numpy as np
import torch

seed = 42
random.seed(seed)
np.random.seed(seed)
torch.manual_seed(seed)
```

## 复现并不只靠一个种子

固定随机种子只是复现实验的一部分，还需要记录依赖版本、模型和数据版本、数据划分与加载顺序、硬件环境，并在框架支持时启用确定性算法。有些 GPU 算子本身可能是非确定性的；跨平台或跨版本运行，即使种子相同，也不保证结果逐位一致。

评估模型稳定性时，也不应只报告种子 42 的一次结果。更可靠的做法是使用多个种子重复实验，并报告均值和波动范围。

## 小结

- 42 是文化惯例，不是统计学上的最佳种子。
- 固定种子有助于复现，但不能单独保证完全一致。
- 正式实验应记录完整环境，并用多个种子检查结果稳定性。
