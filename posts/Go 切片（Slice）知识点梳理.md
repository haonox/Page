# Go 切片（Slice）知识点梳理

> 日常学习笔记，涵盖切片声明、`len` / `cap`、截取、遍历、`append`、底层数组共享、拷贝，以及用切片实现栈。

## 1. 数组与切片

数组 `[N]T` 存放固定数量的元素，长度 `N` 是类型的一部分。切片 `[]T` 描述底层数组里一段连续的元素。切片的长度可以通过截取或 `append` 改变。

**Go 的赋值和传参都按值复制。** 复制数组会复制每个元素的值。复制切片会复制切片描述符，两个切片仍可访问同一个底层数组。数组元素如果含有指针或切片，复制这些元素也可能共享它们引用的数据。

可以用三个字段理解切片描述符：

| 字段 | 含义 |
| --- | --- |
| 起点 | 切片从底层数组的哪个位置开始 |
| `len(s)` | 当前切片包含的元素个数，也是下标访问的边界 |
| `cap(s)` | 从切片起点开始可使用的总槽位数，包含 `len(s)` 已占用的槽位，也可能被三索引截取限制 |

始终有 `0 <= len(s) <= cap(s)`。剩余容量是 `cap(s) - len(s)`。

## 2. 声明与初始化

| 写法 | `len` | `cap` | 说明 |
| --- | ---: | ---: | --- |
| `var s []int` | 0 | 0 | `nil` 切片，可以直接 `append` |
| `s := []int{}` | 0 | 0 | 非 `nil` 的空切片 |
| `s := []int{1, 2, 3}` | 3 | 3 | 用切片字面量指定元素 |
| `s := make([]int, 3)` | 3 | 3 | 已有 3 个元素，初始值都是 `0` |
| `s := make([]int, 2, 5)` | 2 | 5 | 已有 2 个元素，还能追加 3 个 |
| `s := make([]int, 0, 5)` | 0 | 5 | 预留 5 个位置，从空切片开始追加 |

如果你要用 `append` 收集结果，又提前知道大致数量，可以用 `make([]T, 0, n)` 预留容量。如果你要直接给 `s[i]` 赋值，先确保 `i < len(s)`。

## 3. 截取与底层数组共享

### 双索引 `a[low:high]`

取下标区间 `[low, high)`，结果的长度是 `high - low`，容量是 `cap(a) - low`。省略 `low` 时默认是 `0`，省略 `high` 时默认是 `len(a)`。对切片重新截取时，显式的 `high` 最大可以取 `cap(a)`。对于数组，`cap(a)` 等于 `len(a)`。[Go 规范 · 切片表达式](https://go.dev/ref/spec#Slice_expressions)

```go
arr := [5]int{10, 20, 30, 40, 50}
s := arr[1:4]
fmt.Println(s, len(s), cap(s)) // [20 30 40] 3 4

s[0] = 99
fmt.Println(arr)  // [10 99 30 40 50]
fmt.Println(s[:4]) // [99 30 40 50]
```

这里 `s[3]` 会越界，因为 `len(s) == 3`。先用 `s[:4]` 得到长度为 `4` 的切片，才能通过下标 `3` 读到 `50`。

### 三索引 `a[low:high:max]`

结果的长度是 `high - low`，容量是 `max - low`。令 `max == high`，就能把容量限制为当前长度，下一次追加元素时会分配新的底层数组。

```go
arr := [5]int{10, 20, 30, 40, 50}
s := arr[1:3:3] // [20 30]，len = 2，cap = 2
s[0] = 99      // 修改共享位置，arr[1] 也变为 99
s = append(s, 77)
fmt.Println(s)   // [99 30 77]
fmt.Println(arr) // [10 99 30 40 50]
```

截取和切片赋值都产生共享底层数组的切片值。每个切片各自记录长度和容量。改变一个切片的长度，只会改变它当前可访问的范围。

## 4. 遍历切片与字符串

### 遍历切片

```go
s := []int{10, 20, 30}

for i := 0; i < len(s); i++ {
    fmt.Println(i, s[i])
}

for i, v := range s {
    fmt.Println(i, v)
}

for _, v := range s { // 只取值
    fmt.Println(v)
}

for i := range s { // 只取下标
    s[i] *= 2
}
fmt.Println(s) // [20 40 60]
```

- 普通 `for` 便于控制起点、步长和方向。
- `range` 取到的 `v` 是元素值的副本。给 `v` 赋新值只改这个副本，给 `s[i]` 赋值才会写回切片。
- 遍历切片时，`range` 的迭代次数由进入循环时的切片长度决定。循环中追加元素不会增加本次循环的迭代次数。

### 遍历字符串

Go 字符串是不可变的字节序列。`len(s)` 返回字节数，`s[i]` 取到一个 `byte`。本次刷题用到的小写英文字母和括号都占一个字节。需要修改字节时，可以用 `[]byte(s)` 得到可修改的切片。按 Unicode 码点遍历 UTF-8 文本时，用 `range` 取得 `rune`，下标仍表示字节偏移量。需要按码点下标访问时，可以先转成 `[]rune`。[Go 规范 · 字符串上的 range](https://go.dev/ref/spec#For_range)

```go
s := "a中"
fmt.Println(len(s)) // 4 字节
for i, r := range s {
    fmt.Printf("%d %c\n", i, r) // 先输出 0 a，再输出 1 中
}
fmt.Println(len([]rune(s))) // 2 个码点
```

## 5. append 与扩容

```go
s := []int{1, 2}
s = append(s, 3)               // 追加一个元素
s = append(s, 4, 5)            // 追加多个元素
other := []int{6, 7}
s = append(s, other...)        // 追加另一个切片中的元素
fmt.Println(s)                 // [1 2 3 4 5 6 7]
```

`append` 返回长度更新后的切片，通常写成 `s = append(s, ...)`。设追加后的长度为 `newLen`：

- **`newLen <= cap(s)`**：复用底层数组，在旧长度之后写入追加项。已有元素留在原位。
- **`newLen > cap(s)`**：分配新底层数组，复制原切片中已有的元素，再写入追加项。仍指向旧数组的其他切片可以继续使用它。若旧数组是堆分配的且已不可达，垃圾回收器可以回收它。

追加一个元素时，切片已满就会扩容。追加多个元素时，即使还有剩余容量，也要看剩余位置能否容纳这批元素。[Go 规范 · append 与 copy](https://go.dev/ref/spec#Appending_and_copying_slices)

### 新容量会是多少

语言规范保证新容量至少能容纳追加后的所有元素。Go 运行时的 `growslice` 路径先根据旧容量和所需长度计算候选容量。若所需长度超过旧容量的两倍，就以所需长度为候选值。其余情况下，小容量通常以两倍为候选值，较大容量的增长倍数逐渐趋近 `1.25`。内存分配按字节数向上取整，最终的 `cap` 还会受元素大小和分配档位影响。[Go 运行时源码](https://go.dev/src/runtime/slice.go)

例如，在 Go 1.27.1（amd64）中，对装满的 `[]byte` 各追加一个元素，旧容量 `2`、`8`、`1024` 分别变为 `8`、`16`、`1536`。一次扩容需要复制已有元素，连续单元素追加的均摊时间是 `O(1)`。

## 6. 用切片实现栈

在「有效的括号」里，切片末尾是栈顶。左括号入栈，右括号匹配成功后弹出栈顶。取栈顶和出栈之前都要先判空。

```go
var stack []byte
stack = append(stack, '(', '[')

if len(stack) > 0 {
    top := stack[len(stack)-1]
    stack = stack[:len(stack)-1]
    fmt.Printf("弹出 %c，剩余 %s\n", top, stack) // 弹出 [，剩余 (
}
```

出栈只缩短 `len`，`cap` 保持原样，弹出的字节仍留在底层数组里。只要容量足够，再次入栈就会复用这个位置并写入新值。读栈顶和出栈都是 `O(1)`。

## 7. 复制切片

给目标切片分配独立的底层数组，再用 `copy(dst, src)` 复制。`copy` 返回实际复制的元素个数，即 `min(len(dst), len(src))`。

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))
n := copy(dst, src)
dst[0] = 99
fmt.Println(n, src, dst) // 3 [1 2 3] [99 2 3]
```

`copy` 复制的是元素值。对 `[]int` 来说，复制后的元素可以独立修改。对 `[][]int` 来说，外层独立，复制过去的内层切片仍共享各自的底层数组。要让内层也独立，需要逐个复制。

## 8. 常见易错点

- **把容量当下标上限。** 即使 `cap(s)` 更大，直接访问 `s[i]` 也要满足 `0 <= i < len(s)`。
- **给 `copy` 的目标只留容量。** `make([]int, 0, n)` 创建的切片长度为 `0`，作为 `copy` 的目标会复制 `0` 个元素。
- **取 `range` 变量的地址。** 使用 Go 1.22 起的语言版本时，`for _, v := range s` 每轮都有自己的 `v`，`&v` 指向这一轮的元素副本。旧版语义会复用变量。使用 `=` 给循环外声明的变量赋值时，也会复用该变量。想取原切片元素的地址，写 `for i := range s`，在循环体内取 `&s[i]`。[Go 1.22 发布说明](https://go.dev/doc/go1.22#language)
- **用 `==` 比较两个切片。** 切片可以用 `s == nil` 判断是否为 `nil`。比较内容时，先比较长度，再逐个比较对应元素。

## 9. 速查表

| 操作 | 写法 | 底层数组与元素 |
| --- | --- | --- |
| 赋值 | `b := a` | 共享底层数组，各自记录长度和容量 |
| 截取 | `b := a[low:high]` | 共享底层数组 |
| 限制容量 | `b := a[low:high:max]` | 共享底层数组，结果容量为 `max - low` |
| 追加 | `s = append(s, x)` | 容量够时复用，容量不足时分配新数组并复制已有元素 |
| 取栈顶 | `stack[len(stack)-1]` | 读取末尾元素，先判空 |
| 出栈 | `stack = stack[:len(stack)-1]` | 缩短长度，先判空 |
| 复制 | `copy(dst, src)` | 将元素写入已准备好的目标切片 |
